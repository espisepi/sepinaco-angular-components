
Comandos usados para crear este proyecto desde una carpeta padre.

Lo hice de esta manera para instalarlo con angular actualizado

sin modificar angular/cli global, usando npx con angular/cli local.

Comandos: =========================================================

npm init

(ls)

npm install @angular/cli

(cat package.json)

npx ng version

npx ng new sepinaco-angular-components


nvm list        
nvm use v24.16.0
